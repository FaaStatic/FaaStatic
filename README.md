**Offline-first is the thing I actually specialise in.** Realm, Room, and SQLite with queued
sync that survives a bad connection in the field. On COIP Mobile that means job creation,
multi-tab checksheets with conditional validation across 100+ fields, and photo evidence
that uploads when the technician gets signal back.

The typed API layer is generated from the backend OpenAPI spec with Kubb, so there is no
hand-written client code and no schema drift. Around 100 unit and UI tests (Jest, RNTL)
keep it honest.
